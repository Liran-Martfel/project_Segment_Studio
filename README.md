# 🧩 Segment Studio — פילוח אוטומטי (Clustering)

### 🔗 [רשימת המשימות האינטראקטיבית של הפרויקט](https://claude.ai/code/artifact/600c6f71-059c-4354-8c04-15dfa6b86600)
*(קישור זמני — יוסר מכאן לאחר סיום הפרויקט. גרסה מקומית זהה זמינה גם בקובץ [checklist.html](checklist.html) ובנוטבוק [checklist.ipynb](checklist.ipynb).)*

מערכת אינטראקטיבית לניתוח נתונים שמטרתה לגלות קבוצות נסתרות (Segments) בתוך קובץ CSV באמצעות למידת מכונה.
המשתמש מעלה קובץ נתונים, בוחן כיצד הנתונים מתחלקים לקבוצות בעזרת אלגוריתם **K-Means**, ולאחר מכן משתמש במודל **LLM** כדי להעניק לכל קבוצה שם ותיאור קצר. המערכת נבנתה כאפליקציית **Streamlit** לעבודה אינטראקטיבית ונוחה עם הנתונים.

---

## 🔁 תהליך העבודה מקצה לקצה

1. **טעינת נתונים** — העלאת קובץ CSV והצגתו כטבלה.
2. **ניתוח מבנה הקבוצות (Elbow / WCSS)** — הרצת K-Means על טווח ערכי K וציור גרף Elbow לבחירת מספר קלאסטרים מתאים.
3. **חישוב קלאסטרים** — הרצת K-Means עם ה-K הנבחר, הקצאת `cluster_id` לכל שורה וספירת תצפיות לכל קלאסטר.
4. **פרשנות בעזרת LLM** — לכל קלאסטר נבנה סיכום (גודל הקבוצה, ממוצעי פיצ'רים מספריים, ערכים קטגוריאליים שכיחים), שנשלח למודל שפה שמחזיר שם קצר ותיאור בן שורה אחת.
5. **ייצוא לקובץ CSV** — הוספת עמודת `name_cluster` לקובץ המקורי ושמירתו בשם `<original_name>_clustered.csv`.

## 🧠 בונוסים (רשות)

- ✅ **Silhouette Score** — מחושב כבר לצד WCSS עבור טווח ה-K שנבחר.
- ⬜ כפתור **בחירת K אוטומטית**: לפי Silhouette Score נבחר הערך המקסימלי, ועבור WCSS נשאלת שאלת ה-LLM לגבי ה-K המומלץ.
- ⬜ **ניקוי חריגים (Outliers)** — איתור נקודות עם מרחק חריג מהמרכז שלהן והסרתן לפני האימון הסופי.
